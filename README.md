# sharath.press

A personal blog by Sharath about software, problem-solving, and learning.

Read it at [sharath.press](https://sharath.press).

The site is a responsive, searchable journal with topic filters and an in-page article reader. It is built with plain HTML, CSS, and JavaScript, with no build step or dependencies.

## Publishing

GitHub Actions deploys the site to GitHub Pages whenever changes are pushed to `main`.
